# Project Name

Move Dojo

## The Problem

When learning a new fighting game, memorizing and becoming familiar with attacks and strings can be difficult. Aspects like button inputs, frame data (including startup, active, and recovery), safety on block, and hitboxes are all relevant information to know. Depending on the game knowledge like this is very nice to have to give yourself an advantage, but memorizing it isn't easy.

## How It Works

- Creates quizzes based on a movelist for fighting game characters
- Uses the Leitner System for memorization
- Creates card sets for user-defined groups
- Reinforces learning through spaced repetiton
